## Learning Approach

I believe in learning cybersecurity by **doing, not just memorizing**.

Each learning day focuses on:

- Understanding the concept
- Building a strong mental model
- Practicing in authorized labs and safe environments
- Documenting mistakes and lessons learned
- Connecting technical concepts with real security operations
- Creating portfolio-ready work

Build practical, job-ready foundations across **WAPT, SOC, and GRC** while maintaining a public record of my cybersecurity learning and hands-on work.
